# Smart E-Commerce Platform

A modern online marketplace for products, sellers and customers.
Built for the Brolf Tech Remote Internship Challenge 2026 (Project 2).

## Users
- Customers — browse, search, cart, checkout, order history
- Sellers — product management, inventory, order status, reports
- Admins — seller approval, all orders, platform metrics

## Stack
- Frontend: React 18 + Vite + Tailwind + React Router + TanStack Query
- Backend: Node 20 + Express + zod
- ORM: Prisma (MySQL 8)
- Auth: JWT access + refresh, bcrypt, httpOnly cookies
- Tests: Vitest + Supertest
